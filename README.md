## Individual research & projects
- **[arctic-energy-budget-analysis](https://github.com/mc5601/arctic-energy-budget-analysis)** — Arctic top-of-atmosphere radiation and energy fluxes from CERES, ERA5, and ocean reanalysis.
- **Arctic sea-ice attribution** — *research with Prof. Michael Previdi (Lamont-Doherty Earth Observatory); repository private.* Separating the **forced response** from **internal variability** in Arctic sea ice using multiple linear regression (AMO / PDO / AO / PNA drivers), an **optimal-detection** method, and **PCA / EOF** analysis across multi-model large ensembles (CESM1-LE, MIROC6, MPI, ACCESS).
- **[Lightning prediction](https://github.com/mc5601/Lightning_Prediction)** — *course project, individual report.* Predicting lightning occurrence over the continental U.S. from ERA5 reanalysis + GOES-16 GLM, comparing Random Forest, Neural Network, CNN and U-Net under extreme class imbalance (ROC-AUC, PR-AUC, feature importance).
